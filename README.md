# Stupidly Overengineered To-Do App

A hilariously overengineered To-Do app featuring:

- **Dynamic background dots** that pulse, move, and connect with gradient lines.
- **200 unique insults** as notifications when deleting tasks.
- **Scrollable task list** for long lists.
- **Dark/Light theme toggle** saved in localStorage.
- **Settings panel** to customize dot count, line width, speed, and more.
- **Responsive design** that scales with window size.
- **Sound effects** for adding/deleting tasks.

---

## Features

- Add/Delete tasks with fun insults and sound effects.
- Settings persist via `localStorage`.
- Theme toggle between light and dark.
- Animated, interactive background dots with gradient connecting lines.
- Task list scrolls if it becomes too long.
- Fully responsive, scales with browser window size.
